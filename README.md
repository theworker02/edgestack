# edgestack

Edge timestamps and stack durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/edgestack/

## Install / run

```bash
git clone https://github.com/theworker02/edgestack.git
cd edgestack
node src/cli.js
node --test
```
